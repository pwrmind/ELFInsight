# Binary Insight Pro

Интерактивный веб‑инструмент для исследования и редактирования заголовков исполняемых файлов форматов **ELF** (Linux) и **PE** (Windows). Встроенная база знаний на русском языке объясняет назначение каждого поля, помогая изучать внутреннее устройство бинарных файлов.

![Интерфейс Binary Insight Pro](https://via.placeholder.com/800x450?text=Binary+Insight+Pro+Screenshot)

## 🚀 Возможности

- **Поддержка двух форматов**  
  Автоматически определяет Linux ELF (исполняемые, объектные `.o`, библиотеки `.so`) и Windows PE (`.exe`, `.dll`) по магическим байтам.

- **Детальный парсинг заголовков**  
  - ELF: ELF Header, Program Headers, Section Headers с именами секций  
  - PE: DOS‑заглушка, COFF‑заголовок, Optional Header (32/64 бит), таблица секций (`.text`, `.data`, `.rsrc` и др.)

- **Интерактивный редактор**  
  Кликните на любое поле — в боковой панели появится его значение, смещение в файле и форма для редактирования. Доступные варианты подставляются из справочников констант.

- **Встроенная база знаний**  
  Каждое поле сопровождено подробным описанием на русском языке: зачем оно нужно, как влияет на работу ОС и какие значения допустимы.

- **Сохранение изменений**  
  Отредактированные байты сразу записываются в бинарный буфер. Модифицированный файл можно скачать одним кликом.

- **Адаптивный дизайн**  
  Интерфейс построен на Tailwind CSS, корректно отображается на десктопах и мобильных устройствах.

- **Никаких зависимостей от сервера**  
  Вся логика выполняется в браузере на чистом JavaScript (FileReader, DataView). Нет загрузки файлов на сервер.

## 📦 Установка и запуск

1. **Скачайте файл**  
   Склонируйте репозиторий или просто сохраните `index.html` из этого проекта.

   ```bash
   git clone https://github.com/yourusername/binary-insight-pro.git
   cd binary-insight-pro
   ```

2. **Запустите локальный веб‑сервер** (рекомендуется)  
   Из‑за ограничений безопасности браузеров при открытии `file://` могут не загружаться внешние CDN‑ресурсы. Запустите любой статический сервер, например:

   - Python 3:  
     ```bash
     python -m http.server 8000
     ```
   - Node.js (с `http-server`):  
     ```bash
     npx http-server -p 8000
     ```
   - VS Code: расширение **Live Server**

   Откройте в браузере `http://localhost:8000`.

3. **Или откройте напрямую**  
   Можно просто открыть `index.html` в браузере. В этом случае могут не отображаться иконки и использоваться системный шрифт, но весь функционал сохранится.

4. **Используйте**  
   Нажмите «Открыть файл» и выберите любой бинарник (например, `/bin/ls` или `cmd.exe`). Исследуйте структуру, читайте описания полей, вносите изменения и скачивайте результат.

## 📚 База знаний

Описания полей хранятся прямо в JavaScript‑объекте `metadata` внутри `index.html`. Вы можете легко дополнить их или перевести на другой язык. Пример структуры:

```javascript
metadata: {
  ELF: {
    descriptions: {
      e_type: "Назначение файла: 1 — объектный файл, 2 — исполняемый, 3 — динамическая библиотека."
    },
    dictionaries: { ... }
  },
  PE: { ... }
}
```

**Приветствуются pull‑request’ы с расширением справочников и добавлением новых форматов!**
